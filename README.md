# FOXC2-Endothelial-PCHiC
Reproducible analysis of publicly available endothelial precursor promoter capture Hi-C (PCHi-C) data at the FOXC2 locus, including CHiCAGO interaction filtering and conversion from hg19 to hg38 for visualization of long-range chromatin interactions.

Processed FOXC2 Endothelial Precursor PCHi-C Data

Contains a locus-specific subset of publicly available human endothelial precursor promoter Capture Hi-C (PCHi-C) interactions from Javierre et al. (2016), converted from GRCh37/hg19 to GRCh38/hg38.

Processed file: FOXC2_EndP_score5_hg38.bedpe 
Contains 41 significant FOXC2 promoter interactions (endothelial precursor CHiCAGO score ≥5), with both genomic anchors converted to hg38.

Original data source: Javierre BM, Burren OS, Wilder SP, et al. (2016). Lineage-Specific Genome Architecture Links Enhancers and Non-coding Disease Variants to Target Gene Promoters. Cell 167:1369–1384.e19.

Publication: https://doi.org/10.1016/j.cell.2016.09.037 
Original data: https://osf.io/u8tzp/ 
Source matrix: PCHiC_peak_matrix_cutoff5.txt.gz 
Original dataset license: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/

Data processing:

The original matrix contains CHiCAGO interaction scores for 17 cell populations. 

Interactions were selected using: 
FOXC2 promoter bait ID: 278067 
Chromosome: 16 
Cell population: 
endothelial precursors (EP) 
Minimum CHiCAGO score: 5

The original hg19 restriction-fragment coordinates were converted to 0-based, half-open BED intervals. Both interaction anchors were independently converted to hg38 using UCSC liftOver and the hg19ToHg38.over.chain.gz chain file. 
Interaction pairs were reconstructed using their unique identifiers. Original CHiCAGO scores were preserved without modification.

The converted FOXC2 promoter bait is located at: chr16:86558346-86569633

Reproducibility 
The extraction and coordinate conversion workflow is documented in extract_liftover_pchic.py. The analysis uses previously published CHiCAGO scores. No new interaction calling or sequencing experiments were performed.

Attribution and data reuse 
The original experimental data and CHiCAGO scores were generated by Javierre et al. (2016). This repository provides a derived FOXC2-specific subset of those data, selected for significant endothelial precursor interactions and converted from hg19 to hg38.
